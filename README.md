# 이터널 리턴 모작

이터널 리턴 **코발트 프로토콜 모드** 모작 프로젝트입니다.

▶️ [플레이 영상 보기](https://youtu.be/aHRDg0Cus4I)

📅 **개발 기간** : 2025.10 ~ 2025.12 (12주)  
👥 **개발 인원** : 5인

## 🛠️ 사용 기술

- C#
- Unity 3D
- TCP/IP 소켓 프로그래밍
- Google Protocol Buffers
- Oracle Cloud

## 📌 담당 업무

### 네트워크 및 룸 동기화

- `LobbyRoom`, `PickRoom`, `GameRoom` 기반의 룸 상태 전환 및 플레이 흐름 구현
- 캐릭터 선택, 준비, 팀 배정, 게임 시작 및 오브젝트 생성·삭제 동기화

### 서버 권위 전투 시스템

- 서버 권위 구조의 이동, 충돌, 평타 및 스킬 판정 구현
- 스킬 히트박스, 데미지, 상태 이상, 대상 지정 불가 및 아군·적군 판정 처리

### 아비게일 캐릭터

- Q/W/E/R/D 스킬, 표식 및 쿨타임 초기화 구현
- 애니메이션, 이펙트 및 사운드 연동

### 시야 및 오브젝트 시스템

- 부쉬 시야 공유, 와드 설치·감지 및 팀별 오브젝트 표시 구현
- 비콘 점령 로직과 점령 게이지·타이머 UI 연동

### 서버 배포 및 테스트

- Oracle Cloud 서버 배포 및 최대 8인 멀티플레이 테스트
